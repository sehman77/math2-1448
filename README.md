# جاهز للتحصيلي

منصة مراجعة لرياضيات الصف الثاني المتوسط ١٤٤٨هـ: قانون كل درس، وأخطاؤه الشائعة، وأسئلة واختبارات تجريبية بصيغة الاختبار التحصيلي، مقسمة على فصول الكتاب، مع متابعة نتائج الطلاب في Google Sheets.

- `config.js`: رابط تطبيق الويب من Apps Script.
- `common.js`: أدوات الكتابة الرياضية وخريطة فصول الكتاب.
- `chapters/ch1.js` …: محتوى دروس كل فصل في ملف مستقل.
- `app.js`: منطق البرنامج.
